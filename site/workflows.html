先了解它是什么

这是 hyq13886640 在 #2 分享的社区工作流，不是标准角色设定，也不是浏览器在线生图服务。提交者报告在 RTX 3050 8GB 上出图成功；不同模型版本、节点和设备的运行情况可能不同。

本包已经检查 JSON 格式、节点连接、种子与文件完整性。本站没有在 GPU 环境重新执行生图，因此不标注为“一键运行已验证”。

需要准备什么

已有可运行的 ComfyUI、匹配的模型及 TextEncodeQwenImage21 节点。下载包不包含模型权重。

JSON 是 ComfyUI API 任务格式，不是带节点坐标的可视化工程。不要假定任意版本都支持拖入编辑器；下载包提供明确的本地 API 提交方法。

怎么使用与修改

  1. 启动自己已经配置好的本地 ComfyUI，确认模型和节点能被找到。
  2. 解压下载包，在文件夹中运行 python submit.py chibi-seed42.json。默认连接本机 http://127.0.0.1:8188，不上传到本站。
  3. 提交成功会返回任务编号。任务完成后，在 ComfyUI 输出目录查看图片。

想改提示词：编辑 JSON 节点 4 的 inputs.prompt；种子在节点 6，采样尺寸在节点 5。更详细的说明见 使用说明 ↓。
