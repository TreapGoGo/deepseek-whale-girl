# 社区画廊素材

`manifest.json` 是画廊的统一作品清单，记录作品标题、作者、来源、投稿 issue、创作类型、尺寸和展示路径。首页使用静态图片链接，JavaScript 只增强随机排列、手作筛选、复制下载与放大查看。

## 图片版本

- 历史作品沿用已有文件。
- `submissions/issue-NN-MM-preview.webp`：长边不超过 1000 像素的浏览预览。
- `submissions/issue-NN-MM.webp`：保持投稿图片完整尺寸的高质量 WebP 展示与下载版本。
- 原始投稿附件的地址保存在清单的 `attachment` 中；如需要原始文件格式，可从投稿来源取得。
- #26、#27 的多格总览也保留在目录与清单中，标记 `gallery: false`，首页展示其单张作品，避免重复展示。
- #37 收录 12 张精选；93 张完整合集、Prompt 与原始素材由作者仓库提供。

## 署名与来源

创作类型按投稿者说明记录，不根据画风推断。纯人工作品进入手搓专区；使用生成式 AI 或 AI 辅助的作品不归入纯人工专区。转载作品保留原作者；资料缺失时如实记录，不猜测作者。

收录不把图片变成 MIT 素材。网站代码许可与投稿作品许可分别处理。如涉及侵权，请通过仓库反馈联系删除。
