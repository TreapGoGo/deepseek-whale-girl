01 分享作品

把你的二创放进社区画廊

梗图、插画、贴纸、设定图都欢迎。打开投稿表单，把作品图片直接拖进 GitHub 的补充说明框，等上传完成后再提交。请附图片本身，不要只贴聊天分享链接。

亲手绘制、手写或手工制作的非 AI 作品也特别欢迎。投稿时标明“纯人工创作”，作品会收录进专门的手搓专区。

提交 → 维护者整理 → 网站发布 → issue 回复。投稿不会立即出现在网站上；需要补图时，我们也会直接在原投稿中说明。

提交前的小清单

让大家知道作品从哪里来

  • 作者署上你自己或原作者的名字；不清楚时可以注明“作者未知”。
  • 来源附上原帖、原项目或原图链接；原创作品可写“本人原创”。

需要 GitHub 账号来提交网页表单；打开表单后按提示填写即可。任何时候都不要求你改代码或使用命令行。
